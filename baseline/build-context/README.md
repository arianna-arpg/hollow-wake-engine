# Original build context and committed casting

Fourteen checkpoints execute the pinned original World, Cindervigil/Emberbrand
equipment, actual Firebolt payment/continuation, source rebuilds and projectiles.
Two fresh original processes produce the same bytes; no SDK candidate creates
the expected observations. Normal verification must only reproduce and compare.

Diagnostic base overrides, lowLife and a named gauge expose contextual reads.
The same granted instance follows a changed level while retaining investment.
A replacement host cold-restores its saved authored Flame Studies picks at the
current level. An already-paid cast keeps the former instance and its picks.
Current-resource preservation and an explicit overfull clamp are both recorded.

These observations establish the original synchronous boundary. They do not
establish UI allocation policy, authored conditional-grant coverage, asynchronous
durable acknowledgement, a complete private build service or hardware performance.
