# Original account relic and build observations

These 27 original-only checkpoints were accepted before typed item-owner
qualification. Two fresh processes match byte-for-byte against the pinned
source capsule. `acceptance.json` binds the observer, source lock and compressed
and uncompressed bytes. Reproduce with `npm run reference:account-relic-build`;
normal runs refuse changes rather than update the fixture.

The observer uses real World rebuild, account/character save-load and companion
spawn/retirement services. Private fields are read for identity evidence; their
rules are not replaced. See [the boundary](../../docs/account-relic-items.md)
for canonical order, local/client/possession authority and the distinct
same-scope legacy echo versus different-scope UID collision cases. Recorded
behavior is not blanket approval to reproduce lossy legacy repair at a strict
save boundary.
