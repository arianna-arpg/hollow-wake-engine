# Aura activation

The optional `@hollow-wake/engine/auras/activation` service opens an
aura on borrowed actor state. Hosts provide skill context and admitted supports,
current stat/pool queries, retirement and presentation. Content, instances, aura
specifications and modifier arrays retain identity. The service owns no registry,
clock, random source, database or per-frame cache.

An existing skill key exits silently without refreshing duration. An occupied
overdrive lane refuses before context reads. `context` captures skill tags and
instance modifiers in their original order; later stat reads use that same
context. Support admission remains a host policy, including fixpoint tag grants
and passive grafts. Aura delivery alone does not make an aura-tagged support fit.

Toggle reservation uses current mana cost and either full mana capacity or the
90% life-reservation ceiling. Exact limits are admitted; resource clamps follow
the reservation write. A duration graft takes precedence over life reservation,
skips reservation, and evicts finite-duration rows in insertion order under the
rounded cap, with a minimum of one. The service retains one snapshot and its
captured cap throughout retirement callbacks. An index replaces repeated array
shifts without changing that snapshot's order; no measured speedup is claimed.

The overdrive lane opens after ordinary refusal/eviction paths. Positive support
bonuses copy the ally modifier array and add recharge or negative delay modifiers.
The new row owns its affected set and optional zero ledger. Radius, shape,
duration and time retain their sampling order. The map key is evaluated before
row construction: a shape callback can change the instance ID while the row
stays under its earlier key. Later self-source and shell reads see the current ID.

Seals only lower a standing life lock. Self modifiers install after the row and
seal, then shell strength is queried. Shell pool and maximum scale together;
default regeneration uses the scaled maximum divided by five. Nullish defaults
preserve authored zero arc, delay and rate. A new shell replaces an older shell.

Callbacks are trusted and synchronous. Exceptions preserve preceding writes:
for example, a late stat failure can leave an opened overdrive lane before row
installation. No rollback, private-world cloning or deferred effect queue is
implied. Hosts retain living/cast admission, full aura ticking, spatial contacts,
payload execution and durable publication. Original courses combine authored
definitions/supports with explicit diagnostic boundary rows; they do not prove
full scheduling or every authored encounter.
