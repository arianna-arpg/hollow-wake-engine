`0.61.0-candidate.0` and the separately compiled combat package are qualified
engineering candidates. Milestone two remains preserved at
`fa773ec12113206eb0223baaf42fa83596c19c18`.

accounts and persistence remain outside the required runtime.

## Corrections found by composition

Fully initialized proc definitions included 147 registered procs and one rider;
pure module imports alone missed passive-tree registrations. The compiler now
uses an independently frozen original registry. Skills, supports, statistics,
statuses, passive choices, body definitions and carried/throng registrations
likewise use pinned initialized content rather than runtime game startup.

Composition also corrected the encounter-level read used for DoT damage, retained
character retirement ordering, live support admission, possession input lookup,
movement restraint timing, physical squish, native body preflight, and host
lightwell radius draws. Accepted earlier baselines were not rewritten to fit
these changes. New courses were observed in two fresh original-only processes
before freezing.

The original Heating Up buff is consumed on the critical hit that grants it,
so Heat Lost does not subsequently fire in that ordinary sequence. The course
records this source limitation explicitly. This milestone preserves it; balance
corrections require a separate decision and baseline.

Fog occupancy is a host input at the post-actor/pre-projectile phase. The original
observer records actual environmental status requests, then invokes the original
status engine. The SDK applies the recorded requests through its own status
engine. The host retains fog simulation and lightwell survival behavior. On-kill
light placement uses the original no-bounty flag so optional campaign reward
draws do not become a hidden combat dependency.

## Validation and footprint

`npm run verify` includes the new combat coverage runner and installed composition.
`npm run reference:verify` includes every new original observer. Normal gates
verify source/observer/fixture hashes and never recapture accepted results.
The required family matrix points to concrete representative courses.

Local qualification on 15 November 2026 completed all checks in the 148-stage
`verify` recipe and the 63-stage `reference:verify` recipe. The unit suite passed
2,612 tests. The final combat gate passed 66 checks; its original-only counterpart
passed 41. All 70 required authored families are qualified by the runtime receipt.

The initial verification run reached its final combat stage and caught two
focused fixtures that still reflected an earlier host contract. They now use
the SDK's real attribute requirement rule and declare the required spatial
services. The complete combat gate then passed on rerun. The reference recipe
resumed at its thirteenth stage after a local archive-install timeout; its
remaining 51 stages passed. Three cleanup-only harness changes also passed their
original checks and left no scratch folders. Accepted observations were unchanged.

The root engine's retained 96 KiB raw core budget is unchanged. The 80 new
separately loaded combat modules total 497,690 bytes of unminified JavaScript and
have an initial 512 KiB code-size ceiling. They are excluded from historical
component budgets and mechanically forbidden from the eager root graph.
This is a packaging limit, not a CPU or memory performance claim.

The full authored browser bundle is approximately 15 MB minified, including
content and supporting runtime. It has not been qualified on Steam Deck or
older phones/tablets. Content loading, resident memory, frame costs, inspection
allocation and native-host overhead remain explicit milestone-five measurements.
No SQL query or persistence coordinator enters the per-hit path.
