# Skill bar ownership qualification

`@hollow-wake/engine/skills/bar` separates bar references from learned and
equipment-granted ownership. It extracts binding, toggling, swapping, ordered
rebuild callbacks and account slot preferences. The original game adapter
delegates four World methods and three preference helpers while retaining the
original entry points and default arguments.

The [verification receipt](verification.json) records:

- 31 frozen original bar checkpoints and eight preference cases, captured in
  two fresh processes before runtime extraction;
- both original-game and complete prepared-game adapters, with all three game
  type configurations and exact observation bytes;
- 18 cold lookup, 15 active passive-graft, 60 legend, 36 worn-support and 18,773
  catalogue cases, plus the older skill learning/removal and resume courses;
- ten equipment and eight bar faults, detected at their original assertion
  checkpoints, followed by restored controls;
- complete-pipeline passive handoff fault detection, simulation smoke and the
  older 4,103/8 passive courses;
- all 1,693 SDK unit tests, the full package/boundary/fault verifier and the
  full original-reference verifier.

The [mechanical comparison](mechanical-proof.json) checks all seven extracted
bodies after explicit host-port substitution, local alias removal and
single-statement control-block normalization. Run
`node evidence/skill-bar/check-mechanical.mjs` to reproduce it. Argument/default
forwarding, live body replacement and callback failures are covered separately
by installed and independent unit tests.

The passing raw installed-game preflight is retained as its original receipt.
Its recorded runtime, adapter, harness and package metadata source hashes match
the final files. The complete adapter and isolated package checks additionally
cover the final documentation and consumer checks. The receipts are not rewritten
to imply that every packed archive was identical.

The initial broad run caught the new module being counted in both its separate
bar budget and the older `skill-*` family. The [one-line budget repair](budget-repair.json)
excludes precisely that module from the predecessor family. No numeric limit or
runtime byte changed. The full SDK verifier was rerun; its passing receipt and
the initial failure are both retained.

The optional module is 3,777 bytes of unminified JavaScript within a separate
4 KiB budget. It adds no runtime dependency, eager core import, database query
or per-frame phase. Package size is not a measured speedup or device result.

[Retention](retention.json) records cleanup and existing worktrees. No worktree
was created. The original game checkout and index were not edited. Existing
source capsules, dependencies and unfinished work remain available.

Native learned-book/bar/grant ownership and private candidate publication remain
the next integration boundary. This milestone does not expand native equipment
admission or qualify physical Steam Deck/mobile performance. The exact published
commit passed both Windows 2025 and Ubuntu 24.04 in
[run 42569986309](https://github.com/arianna-arpg/hollow-wake-engine/actions/runs/42569986309).
[Hosted evidence](hosted.json) records independent checks of the downloaded
reports and logs; [public readback](public-readback.json) verifies published bytes.
