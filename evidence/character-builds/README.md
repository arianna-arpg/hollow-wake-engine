# Character build evidence

The optional durable character builder composes stats, passives, equipment, learned and granted investment, and body-free companion declarations. Its separate authored-content package runs without the original game. See [the contract](../../docs/character-builds.md) and [verification summary](summary.json).

All mandatory local checks use one frozen candidate. Original observations come from the pinned game in fresh processes; ordinary checks do not rewrite expectations. Installed/browser contracts include deliberate faults and restored controls.

The installed Node lifetime check verifies that preceding skill instances can be collected after 32 rebuilds while the current build remains usable. It is not a retained-heap, throughput, device or native-engine performance measurement. Running-character adoption, full workshop command integration and live publication remain separate work.
