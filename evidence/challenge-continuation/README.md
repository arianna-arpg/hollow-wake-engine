# Challenge continuation evidence

The optional copy service preserves controller-owned state over an admitted detached host graph. See [the API contract](../../docs/challenge-continuation.md) and [verification summary](summary.json).

The full verification and reference runs use one frozen set of source files. Original observations are retained under `baseline/challenge-continuation`; normal checks do not regenerate them. The composed game comparison includes the existing 61 observations, the new copy scenarios and 25 identical combat episodes.

Code-size bounds do not establish physical-device performance or complete native engine support.
