# Summon service qualification

Full verification passes 123 commands and 2,141 unit tests; all 44 reference
commands pass. Installed/browser consumers pass 56 contracts and 35 deliberate
faults. Both public and direct-source types pass. Birth is 10,618 bytes and
offspring is 1,483 bytes; the selected browser bundle is 6,293 bytes. These are
package sizes, not CPU or allocation budgets.

Seven frozen original courses retain 117 observations and 108 original fault
checks. The installed game compares 345 observations across twelve modules,
62 installation guards, ten integration faults and four private companion
contexts with fifteen stages. Game, launcher and simulation types pass. The
fully assembled game matches all 25 combat episodes when compared with the
same assembly retaining only the original summon birth and offspring methods.
After reference/tool setup, run npm run adapter:summons-composed to reproduce.

Candidate failures and their corrections remain recorded. In particular, the
explicit delivery-override check was repaired before promotion. Accepted
original observations were not rewritten to accommodate the extraction.

Performance acceptance remains open. The contact-kernel benchmark was deferred
after three preflight samples found other CPU-heavy work. Two earlier summon
timing attempts were rejected for contention. Diagnostic profiles point toward stat
evaluation, actor initialization and context derivation for further study;
they establish no speedup or allocation improvement. The actor initializer
sample location does not attribute its entire cost to the ID increment.
