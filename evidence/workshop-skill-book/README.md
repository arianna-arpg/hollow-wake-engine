# Workshop learned-book ownership

The optional provider separates learned payload ownership from eight action-bar
references. Explicit promotion introduces crafting-session/v4; existing v1/v2/v3
saves retain their behavior. New-format restore preserves deliberately blank
bindings. See [the contract](../../docs/workshop-skill-book.md).

[Full verification](verification.json) passed 1,705 tests, all required package
and fault checks, and the complete original-reference verifier. Its source
hashes stayed unchanged. The original game checkout and index were not edited.
The main verifier was explicitly paused during the penultimate package check.
Its unchanged script and retained log prove the completed prefix; the two
unfinished checks were rerun after resume. The receipt identifies these segments
and preserves the interrupted run rather than implying one uninterrupted pass.
[Package qualification](package.json) runs eleven independent ownership contracts
through an offline installed archive and a hostile-global browser bundle, checks
public types, detects eight deliberate faults, and reruns the restored control.

The [initial package preflight](package-initial.json) caught a weakness in the
test observer: a deliberately broken promotion reached a property access before
an explicit success assertion. The assertion was strengthened without changing
runtime behavior. The [second preflight](package-preflight.json) and the full
verification both passed; the initial logs are retained.

[Native qualification](native.json) rebuilds the opt-in entry and checks the
qualified Windows x64 ABI. All 579 complete predecessor replies match the frozen
source course; 32 new text requests exercise promotion, exact blank restore,
two private workshop proposals, abort, retry, stale tokens and commit. The new
course has independent assertions and is then replayed unchanged through native
code. It is new behavior evidence, not an original-game v4 save baseline.

All four native configurations passed: 32 and 48 MiB without startup collection,
32 MiB with startup collection, and ten predecessor repetitions at 32 MiB with
startup collection followed by the new course. The largest tracked allocation
peak was 30,868,753 bytes; all created hosts released every tracked byte and block.
The native entry bundle is 171,088 bytes. These are desktop allocator results,
not total process memory, a measured speedup or physical-device acceptance.

The optional module is 5,707 unminified bytes within a separate 6 KiB cap. The
tested workshop browser composition is 172,723 minified bytes within 192 KiB.
No dependency, eager core import, database query or per-frame phase was added.

[Native input delta](native-input-delta.json.gz) contains only the new bundle and
course. It references the already published frozen content/course capsule by
hash, avoiding another copy of that large input. Run
`node evidence/workshop-skill-book/check-native-inputs.mjs` to verify all four
reconstructed input byte counts and hashes. With the recorded Node/zlib toolchain
it also reconstructs the exact original archive hash. The native runner remains
available at [its reproduction script](../../scripts/verify-workshop-skill-book-native.mjs).

[Retention](retention.json) records removal of this run's temporary fixtures and
the preserved worktrees. Two small native evidence directories remain locally
as source records; no project, dependency tree or worktree was duplicated.

This is build-data ownership. Equipment grants, shared-account preference writes
and live combat publication remain separate integration work. Published engine
packages keep their default entry; Unity/Godot/Unreal and Steam Deck/mobile
coverage is not expanded by this result. The exact public commit passed Windows
2025 and Ubuntu 24.04 in [run 42650680856](https://github.com/arianna-arpg/hollow-wake-engine/actions/runs/42650680856).
[Hosted receipts](hosted.json) validate the downloaded source hashes, complete
contracts, types and all eight fault logs. [Anonymous public readback](public-readback.json)
checks seven published files byte-for-byte.
