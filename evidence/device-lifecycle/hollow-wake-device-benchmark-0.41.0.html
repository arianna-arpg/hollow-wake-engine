# Source provenance

Derived from `arianna-arpg/arpg-game-world`, authored by Arianna.
The original PolyForm Noncommercial 1.0.0 license is preserved verbatim in `LICENSE.md`.
No broader distribution or commercial rights are granted by this extraction.

`baseline/source-lock.json` identifies the original commit, selected source paths,
working-tree overlay and SHA-256 hashes for every reference source file.
`baseline/source.tar.gz` carries the committed source needed for offline
reconstruction because the captured local revision was unavailable from upstream.
`baseline/overlay/` preserves relevant unfinished source as exact bytes without
altering or committing anything in the original game repository.

`src/stats.ts` is a mechanical extraction of `StatSheet`, subsequently refactored
for rule ownership, defensive copying, bounded caches and indexed trade lookup.
`src/combat.ts` re-expresses the selected damage arithmetic in compiled numeric
tables. Independent reference fixtures are generated by the original implementation,
not by this SDK.

The raw selected authored definitions and complete exported stat catalogue remain
under `baseline/`; the small shipped content pack is an explicitly limited projection.
No source from an unrelated project is vendored.
