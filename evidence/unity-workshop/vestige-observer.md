# Explicit types for the second virtual observer

Review of all game-adapter type-check harnesses found the same implicit
ambient-type lookup in the vestige observer as in the conduit observer.
It now selects the pinned reference tooling's Node declarations explicitly.
Existing harnesses that write TypeScript configurations already declare
their reference type roots.

The [local rerun](vestige-observer.json) executes the original catalogue and
inlay observations, installed package/adapter replay and existing fault
controls. Production code, original fixtures and the Unity archive do not
change. This prevents the next clean-reference stage from depending on a
developer-machine ancestor.
