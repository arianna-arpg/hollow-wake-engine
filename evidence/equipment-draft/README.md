# Private equipment preparation qualification

This milestone adds the optional `skills/equipment-draft` entry. It copies the
equipment derivation graph while preserving ownership aliases and origin links.
Existing grants retain their current investment in the private graph; replacement
grants follow the existing restoration policy. Live actors and casts remain
untouched during preparation.

The installed archive passes eight ownership/failure contracts, browser isolation,
public TypeScript consumption, six deliberate-fault controls, and a restored
control. In the pinned original game's continuity course, all 36 private rebuilds
leave their source unchanged and match the actual installed derivation. All 47
frozen observations still match. See [qualification.json](qualification.json),
its compressed logs, and [summary.json](summary.json) for source and artifact hashes.

All 107 SDK verification commands passed on the recorded inputs, including 1,725
unit tests. This was a split run: the first 52 commands passed before a Windows
profile-temp access error interrupted a package consumer. The exact remaining 55
commands passed with temporary work redirected into the workspace. This is not
a claim that one uninterrupted `npm run verify` invocation exited successfully.
[sdk-verification.json](sdk-verification.json) records the commands, failure,
resumption and source hashes; both console logs are retained compressed. The full
`reference:verify` chain separately exited successfully; its log is also retained.
An earlier package-cap failure was corrected by registering the new optional
module separately; predecessor limits were not raised.

The new unminified module is 5,221 bytes; its minified browser composition with
equipment derivation is 6,933 bytes. The respective limits are 8 KiB and 16 KiB.
These are code-size results, not device latency or memory measurements.

Cleanup removed 79 workspace test folders and 34 profile temporary folders.
No worktrees were created and no new large test folders remain. The cleanup
receipt and package-budget report are included here.

Workshop save coordination, account preference authority and acknowledgement-time
live publication remain open. The original-game course excludes companion grants
and active aura/summon retirements; independent contracts check their private
routing, not complete World effect parity. This milestone does not expand native
engine package admission or establish Steam Deck/mobile performance. See the
[runtime contract](../../docs/equipment-skill-draft.md) and the
[completion matrix](../../docs/completion.json).
