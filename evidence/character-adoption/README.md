# Running-character adoption evidence

The optional durable character builder can adopt trusted observations of a running character into an independent investment graph. It preserves source order and existing skill investment, including investment above a lowered level budget. It checks the complete grant and companion declarations. See [the contract](../../docs/character-builds.md) and [verification summary](summary.json).

One frozen candidate passed all mandatory local checks. Five unchanged original observations join the existing 93 build observations. Installed original-game checks include a paid cast and its later projectile; adoption does not advance or replace the running actor. Installed/browser contracts include deliberate faults and restored controls.

Cold opening and adoption each have a Node lifetime check: preceding skill instances are collectible after 32 rebuilds while the current build remains usable. This is not a heap, throughput or device measurement. Complete workshop command integration, versioned save migration, account persistence and acknowledgement-time live reconciliation remain unfinished.
